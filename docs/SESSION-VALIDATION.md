### 原生待验收

本轮未操作用户真实会话数据、未以云端对话验证删除：

1. 重启 Tauri 桌面壳，新建并命名，发送多条文字；侧栏条目不随轮次增加。
2. 右键重命名，发送后续消息并重启；名称保持、已有对话仍可读取。
3. 播报或录音时删除当前会话；旧声音停止、旧内容不继续追加，新会话可输入。
4. 删除非当前会话；当前对话保留。删除最后一个后可在空白会话发送。

删除只清理 Session 对话归档与 Worker 内存上下文，不清理独立调研证据，
不实现跨进程重启后的 Pi 上下文恢复。Worker 传输故障时删除事务仍保留，
客户端显示后台清理失败提示，需重启清理残余内存。
