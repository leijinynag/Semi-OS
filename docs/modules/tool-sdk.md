# tool-sdk

目标路径：`packages/tool-sdk/`。工具契约、回执与验证类型。

## 职责

- 提供共享工具契约，供自定义工具登记到 Tool Registry。
- 规定每次工具尝试的可审计回执：策略、耗时、结果类别和验证信息。

## 边界

- 记忆检索不算执行工具。可见的 `TaskRun` 在 Agent 请求执行工具时开始或继续。
- `read` 和 `local_write` 默认自动执行。外部副作用和特权动作默认需要确认。
- 不确定的外部结果是 `unknown`，对账之后才能重试。
- 设计中的首批自定义能力是浏览器、桌面、Coding Agent 和记忆工具。
  名称出现在契约目标里，交付状态以 `tasks.md` 和验收记录为准。
- Lark 只使用已登记的结构化工具。超时发送不盲目重试。

## 关键依赖

- `packages/agent-worker`：注册与调用。
- `crates/host`：特权动作的策略与验证。
- `packages/protocol`：跨进程的工具请求与回执。
