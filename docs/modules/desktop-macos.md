# desktop-macos

目标路径：`crates/desktop-macos/`。macOS 辅助功能与屏幕观察。

## 职责

- 向 Host 提供辅助功能语义上的新鲜观察。
- 在 Host 策略和当前桌面租约内，执行一次原子的原生动作。
- 把观察、动作和验证结果交回 Host，由 Host 写入可审计记录。

## 边界

- 原生自动化优先使用辅助功能语义；截图和受约束的低层路径是后备。
- 权限是能力输入。用户明确要求时，客户端才可以打开系统设置。
- 人工接管使桌面租约和全部元素引用失效。
- 屏幕录制权限不表示视觉模型可用。在真实的图像调用和目标绑定证据
  出现之前，视觉回退保持不可用。
- 平台集成若必须使用 `unsafe`，应隔离并写明原因。

## 关键依赖

- `crates/host`：策略、租约、一次原子动作和验证。
- `crates/storage`：动作与未知结果经 Host 持久化。
